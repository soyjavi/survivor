# Tool Storage

Tools rust, blunt and get lost when stored badly. A simple system protects them and saves time. Store each tool in the same place every time, so you can find it in the dark and notice quickly when one is missing.

![Wall board: table-grid with a knife, saw, hammer, axe outline each with a label, empty outline with caution as missing tool; each tool has exactly one place, so a gap shows a missing tool at a glance.](assets/tool-storage-1.svg)

## Why it matters

A tool is only useful when it is ready. Rust, dull blades and cracked handles usually develop out of sight, and a tool kept in a jumbled box may be found only when the job is already urgent. Good storage turns the tool collection from a pile into a system: each item has a place, each place shows when something is missing, and the tools last far longer. Money spent on tools is protected by the same routine.

## Keep them dry

- Store tools in a dry place, off the floor.
- Oil metal parts lightly, especially blades and tools that will not be used for a while.
- Keep silica gel packs in the box to absorb moisture.

## Keep them organised

1. Group tools by job: cutting, fastening, measuring, electrical.
2. Use a box or wall board, with outlines or labels for each tool.
3. Keep a short list of the tools inside the box.

![Box: table-grid with three divider trays labelled cutting, fastening, measuring; knife and saw in the first, hammer in the second; each job has its own tray, so tools for one job stay together; NEEDS: tool-box.](assets/tool-storage-2.svg)

## Step-by-step in detail

Setting up a wall board:

1. Choose a dry, well-lit wall away from the sink, the stove and any outside door, where condensation and draughts are least likely.
2. Mount a board or rail into solid wall fixings, with the top edge at about shoulder height so every item sits within easy reach.
3. Place the heaviest tools lowest, and the lightest highest.
4. Hang each tool by its handle, so the blade or head does not rest on another tool.
5. Draw or fix an outline around each tool, and write the name beside it.
6. Count the tools after hanging them, and note the total on the monthly card.

## Keep them safe

- Store blades in sheaths or covers.
- Keep tools away from children and locked when not in use.
- Store fuel and chemicals in separate, labelled containers. See Storing Fuel.

## Check regularly

Once a month, check handles for cracks, blades for rust and chips, and fasteners for looseness. Write down anything that needs replacing, and do it before the next job. Take a few minutes after each use to wipe tools and return them to their place, because the routine is what keeps the system working.

## Adjusting for conditions

- **Humid climates** speed rust. Use a sealed box with desiccant, and check it more often in the wet season.
- **Cold, dry climates** make plastic brittle, and handles can crack when struck. Store tools in a warm room, and keep them away from unheated outbuildings.
- **Salty air** attacks steel quickly. Wipe blades with a light oil after each use, even when they look clean.
- **Shared storage** in a vehicle or a shelter is exposed to knocks. Pad the box, and secure it so it does not slide.

## Common mistakes

- Storing tools wet, which lets rust form inside the box.
- Putting heavy tools on high shelves, where they can drop.
- Leaving blades uncovered in a drawer with other metal.

## Troubleshooting

- **Rust spots appear quickly:** the box is damp or the tool was put away wet. Clean the spots, dry the tool fully, and move it to a drier place.
- **A tool keeps going missing:** the outline or label is unclear, or the place is shared with another job. Relabel the space, and check the list before and after each job.
- **Oil drips onto the work surface:** the tool was over-oiled. Wipe the excess away, and use a smaller amount next time.
- **Handle loosens in the hand:** the fixing is worn or the wood has shrunk. Tighten or replace the fixing, and check the monthly card for other loose items.

## Checklist

- [ ] Tools dry and lightly oiled
- [ ] Each tool has a labelled place
- [ ] Blades sheathed or covered
- [ ] Monthly check done

## Practice before you need it

Once a season, empty the storage box, clean it and put everything back in its place. Time the process, and aim to finish in under half an hour. Practise finding a named tool with the lights off, so you know whether the labels and outlines are clear enough for a dark night.

## When it fails

If a tool has rust, clean it with a stiff brush, dry it, and oil it. If a handle is cracked, remove the tool from use and replace it. If a tool is missing from its place, check the other storage areas before you buy a new one.

**Warning:** never store tools in a place where they can fall on someone, or on a shelf above a sleeping area.
